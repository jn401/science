# 实验接入指南

## 接入原有显微镜程序

1. 先保留原 HTML 和全部图片、脚本、音视频的备份，确认能独立运行。
2. 将原文件完整复制到 `experiments/microscope/original/`。若原程序是单文件，可保留原名，也可将副本命名为 `index.html`。不要用本站模板覆盖原实验。
3. 检查素材引用。推荐相对路径，如 `./images/cell.png`；以 `/` 开始的路径会指向整个域名根目录，在 GitHub `/science/` 下可能出错。优先保持目录结构；若必须修改路径，另留原版并记录差异。
4. 在 `data/experiments.json` 中将显微镜的 `entry` 设为 `experiments/microscope/original/index.html`（以真实文件名为准）。把描述中的“待接入”改成经过核实的实际功能，完成下列检查后将 `status` 设为 `ready`。
5. 运行 `npm run check`、`npm test`、`npm run build`，再在浏览器中检查首页 → 目录 → 模块详情 → 进入实验 → 返回目录。

统一外壳通过 iframe 加载原实验，上方保留返回目录按钮。支持全屏的浏览器会出现全屏按钮。若原实验不适合嵌入，可选择“单独打开”；独立页面的返回操作由浏览器提供。手机仍需测试原实验的拖动、缩放、触控、文字大小以及旋转屏幕后状态是否保留。网站外壳不会自动使旧程序适配手机。

`ready` 模块在运行前还会检查入口响应。如果平台把不存在的文件也返回首页和 200 状态，仅靠此检查无法判断程序内容，发布验收仍需实际操作实验。

## 增加独立模块

复制一条目录记录，修改 ID、文字、器材图片和问题。支持以下状态：

| status | 页面标签 | entry |
| --- | --- | --- |
| `planned` | 规划中 | `null` |
| `pending` | 待接入 | `null` |
| `ready` | 可进入 | 已检查的站内 HTML 路径 |

完整字段示例（待接入状态）：

```json
{
  "id": "new-experiment",
  "title": "你的实验名称",
  "shortTitle": "实验简称",
  "category": "物质科学",
  "grades": ["四年级"],
  "status": "pending",
  "image": "assets/images/magnifier.svg",
  "imageAlt": "请换成与实际器材一致的图片描述",
  "summary": "一句话介绍探索方向。",
  "description": "说明当前接入情况和经过核实的功能。",
  "equipment": ["实际器材名称"],
  "questions": ["希望学生观察什么？"],
  "entry": null
}
```

示例复用了现有图片路径，实际新增时应替换为符合该实验的本地器材图。文件名推荐英文小写和连字符，ID 唯一且接入后保持稳定。入口只接受 `experiments/<同一ID>/...html`，不接受站外地址、查询参数或 `..` 路径。

分类与年级为维护者标注，应按实际教材调整，当前预留模块不代表已经完成课程审核。不要在目录中写入学生姓名、照片或个人账号信息。本站没有上传、云端保存或学生数据收集功能。

新资源会自动进入目录，首页显示目录数据的前三项。若需调整首页顺序，在 JSON 中调整记录顺序即可。
